# Door_To_Hex
Created by: Aiden Hicks, Sorsha Berle and Karmyne Ledet

## Abstract

Door_To_Hex provides a card model for storing access-card information associated with doors. It translates card data provided as a Facility Code (FC) and Card Number (CN), or in AWID26 format, into hexadecimal.
